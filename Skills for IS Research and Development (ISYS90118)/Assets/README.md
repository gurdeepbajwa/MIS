# Skills for IS Research and Development Assets

Store official course files and source material here.

Use the naming pattern `Week NN - Descriptive Topic Asset Type.ext`, such as:

- `Week 01 - Descriptive Topic Slides.pdf`
- `Week 01 - Descriptive Topic Transcript.txt`
- `Week 01 - Descriptive Topic Reading.pdf`

Add each asset to this index after it is named and filed.
