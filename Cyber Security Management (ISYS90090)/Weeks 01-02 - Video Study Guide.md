# Weeks 01–02 — Video Study Guide

Course: [[Course Overview|Cyber Security Management (ISYS90090)]]

## Purpose

Use video to gain a first view of each topic, then use the course notes to add exact terms and detail. After a break of one to three days, return to active recall and applied questions.

The outside videos support study but do not replace the course slides, transcript, readings, or lecturer's terms.

## Study Wave

1. Watch one entry video without trying to write full notes.
2. State the main idea in two or three lines from memory.
3. Read the linked course section and add the exact course terms.
4. Stop when the content load feels high enough.
5. Return after one to three days and answer recall questions without notes.
6. Move into distinctions, multiple choice, and case questions if recall is sound.

## Optional Deep Dive — Formal Risk Frameworks

- [NIST Risk Management Framework Fully Explained — Simply Cyber](https://www.youtube.com/watch?v=Z2okRecJC7E)

This goes beyond the Week 1–2 baseline. Use it only after the triplet model makes sense. It shows how a formal risk process turns broad security aims into choices and controls. Do not replace the course's triplet terms with the video's framework terms in an exam answer.

## First Return Session

On the first return, start without notes:

1. Define asset, threat, vulnerability, risk, and control.
2. Give one confidentiality, integrity, and availability example for the same asset.
3. Explain why formal, informal, and technological controls depend on each other.
4. Explain the main difference between the CEO, CIO, and CISO in a risk decision.

If these answers are sound, move to a short case and ask the user to choose controls under a fixed budget.
